# Pipeline Gráfico Básico

1. **Model Space** – coordenadas locais do objecto
2. **World Space** – aplicação de transformações de modelo (T, R, S)
3. **View Space** – transformação de camara (não implementada neste projeto simplificado)
4. **Clip Space** – projecção (perspetiva ou ortográfica)
5. **Screen Space** – divisão perspetiva + viewport transform
